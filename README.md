# ✅ To-Do List - HTML, CSS, JS + FastAPI

A full-stack task management system with a **vanilla HTML/CSS/JavaScript** front-end and a **Python back-end built with FastAPI**.

## 🚀 Features

- Add tasks
- View the task list
- Mark tasks as completed
- Remove tasks

## 🔌 API Endpoints

Each task has the format `{"descricao": "text", "concluida": false}`. Tasks are identified by their **position (index)** in the list, starting at 0.

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/tarefas` | Lists all tasks |
| POST | `/tarefas` | Creates a task. Body: `{"descricao": "text"}` |
| PUT | `/tarefas/{indice}` | Marks the task as completed |
| DELETE | `/tarefas/{indice}` | Removes the task and returns it |

With the back-end running, the interactive documentation generated by FastAPI is available at `http://127.0.0.1:8000/docs`.

## ▶️ Running Locally

Requirement: **Python 3** installed.

### 1. Clone the repository

```bash
git clone https://github.com/lucasz-gabriel/REPOSITORY-NAME.git
cd REPOSITORY-NAME
```

### 2. Back-end

```bash
cd Backend
pip install fastapi uvicorn
uvicorn main:app --reload
```

The API will run at `http://127.0.0.1:8000`.

### 3. Front-end

With the back-end running, open the `index.html` file in the `Frontend` folder using **Live Server** (VS Code extension) or an equivalent tool.

## ⚠️ Limitations

- Tasks are stored **in memory only**: restarting the server erases everything.
- Tasks are identified by their index in the list, so removing one shifts the indexes of the following tasks.
- There is no handling for non-existent indexes (the API returns a 500 error).
- Completed tasks can't be unchecked, and descriptions can't be edited.
- CORS is open to any origin (`*`), which is fine for development but not for production.
